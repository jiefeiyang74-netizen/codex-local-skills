# 视频风格选择与执行

## 选择入口与项目记录
每个全新视频任务，在写定稿、配音或分镜前询问一次：选【经典黑底·动态演示】classic_black，还是【米白讲义·启发推导】paper_guided？不能把上一条视频的选择自动带入下一条新题/新视频。用户明确说“今后都用X”“这次你决定”“不用问风格”等时遵从新授权并在本项目 selection_source 记录来源；不将一次授权扩展成永久偏好。用户本次请求已明确风格，或继续/修复已有且已锁定风格的项目，不重复询问。只做素材分析或 Skill 维护不触发选择。等待回答时可做只读素材检查、数学验算，不默认开始依赖风格的工作。旧项目未记录时先从实际项目确认旧风格；运行器缺省 classic_black 只是兼容行为，不能替代新任务询问。

在 request.json 同目录保存独立 style-selection.json：
```json
{"schema_version":1,"selected_style":"paper_guided"}
```
必填这两个字段和两个既定风格 ID；可选 selection_source 为不超过500字符的选择/授权来源说明（仅留项目，不收入Skill）；不往 request/storyboard 注入新字段。每个项目独立目录；已锁定选择随项目保存。运行器将实际选择复制到 attempt、写入 manifest，并绑定 geometry 渲染身份；切换风格必须新预览，不能复用旧风格通过证据。没有已知其他风格证据的旧输入缺侧车时仍按 classic_black 兼容执行；恢复项目若原 attempt/manifest 已记录 paper_guided，须按[恢复流程](director-and-editing.md)核对并补齐侧车，不能静默回退黑底。

## classic_black — 经典黑底·动态演示
保留既有黑底、顶部暖黄标题、白色公式、红色关键结果和原有布局、动作语义。图形颜色/尺寸/方向连续，旧任务不迁移。音色、语速不随风格切换。

## paper_guided — 米白讲义·启发推导
后续新纸面分镜默认采用已批准的参考画面语法：浅黄底、深墨正文、细框轻偏移影、紧凑左对齐公式框和小阶段标题。通过 geometry-1.9.6 的显式字段实现；这是策划默认，不改变省略字段时的运行器默认。经典风格与已锁定旧项目保持原状，不自动迁移。字体、背景与框字段见下节，不引入 TeX 或纸张纹理，也不把单题画面审核当作所有视频已经验收。

当前纸面风格仅接入 geometry-1.0。generic/v3 固定竖版模板不支持该风格，运行器明确拒绝，不静默回退或伪造支持。内容必须确实适配 geometry 能力，不能只为换主题假冒几何管线。

正式证明按项目画幅安排稳定大图与紧凑推理区：横版可左图右式，竖版可上图下式；先遵循用户画幅，不把比例和框数做成强制模板。页眉与小阶段标题清晰分级；式子左对齐，步骤框按实际短行设高度，不拉成等高大白卡。使用 plot_rect/formula_rect（画面坐标[中心x,中心y,宽,高]）与显式 panel/text 定位，freeform+steps 可保留自行声明的页眉。正式图不漂移，边、角、淡填色使用项目锁定的一对语义色；待证与已知严格分区。手机宽度仍须看清完整关系，不靠机械缩字塞满。省略新字段的既有自动标题、白卡与布局保持兼容。

主图应清晰占据主要绘图区。`world_bounds` 按本章真实对象及需要展示的运动/构造范围设置，只加适量留白；不要因范围过大让复杂题主图缩成小图。长公式不能机械缩小到不可读：优先按推理步骤拆成短行、分阶段呈现，保留关系和等号两侧的完整含义，并检查实际字号与真实画面可读性。

### 已确认参考与沿用版式

用户说“参考已确认版式”“沿用上一条”“恢复旧版”时，先取得并实际查看可读的已确认参考帧，或读取已确认旧分镜及其布局对象；仅有风格名、色板、旧文件名或“上次通过”记录不算取得版式。多个版本时以用户指认的版本为准。材料不可读或缺失时先查项目现存参考/旧分镜；仍无依据才询问关键缺口，继续不依赖版式的工作，不把重新设计称为沿用。用户本次新要求优先；这类指令已明确风格时不重复选择，但不自动覆盖以后所有新题。

写分镜前在项目既有规划记录中对齐：画幅与内容画布、外边距、图框和推理列的比例与间距、字体/字重/字号层级、线宽、完整 frame、header、紧凑 step、轻影。这里的 frame/header/step 是视觉角色，不是新增 JSON 字段。颜色相同而结构不同不算模板复用。参考截图先排除播放器黑边、进度条和控件，以内容画布归一化；不把参考题目、阶段文字、对象 ID 或音频搬进新题。

#### 4:3 正式证明布局基线

仅用于 paper_guided 的 4:3 正式证明，且用户没有另定布局时；明确沿用时仍先对照实际已确认材料。不是独立片头、16:9、竖版或 classic_black 的强制布局。其他画幅重新分配空间，不改用户 canvas 来迁就模板。

| 区域 | 内容画布归一坐标（左上原点，x/y/w/h） | 结构要求 |
| --- | --- | --- |
| 外边距 | 约 0.04 | 左右及页眉保留呼吸空间 |
| 左图完整框 | 0.043 / 0.173 / 0.481 / 0.665 | 四边细框完整，不能只靠 plot_rect；题图及标签在框内留白 |
| 右推理列 | x=0.547，y=0.173，w=0.407 | 首卡顶边与左框齐平，紧凑堆叠；高度随内容，不撑满整列 |
| 页底细线 | y=0.87 | 横贯内容区，留出图框底部间距 |

左上小“数学”标识，右上小“几何”页眉（可替换为本期学科或系列名，不复制他人品牌），下行左对齐加粗章节标题；不得退回大号居中自动标题。右卡从顶部开始放小语义标签，再放左对齐短公式；区分已知/待证/推导，不用一张大公式卡替代。面色、深墨、细线及右下轻偏移影按下文显式声明；线宽与字形比例都参与参考对齐，不以黄底相同代替。

#### 真实字段与最小模板

[4:3 布局片段](../examples/paper_layout_4x3.json)只含真实支持字段，是合并用的布局片段，不是可直接运行的完整 storyboard。示例文字“观察与推导”“关系示例”“变形示例”和恒等式只用于说明字形与位置，不锁定任何题目的阶段。使用时将 paper_palette 合入顶层，将章级布局合入对应正式证明章；按本题替换 header/series_header/stage、步骤标签、公式、对象 ID，并按内容增减步骤。由本期分镜提供 schema_version、title、canvas、narration、audio_duration、章 id/title/start/end/world_bounds、真实图元、actions/checks；时间只能来自本期音频。不要把参数说明、占位文本或额外布局元数据塞入运行 JSON，也不要拿示例恒等式当本题依据。

- 4:3 画面坐标宽12、高9：归一矩形转换为 `[12*(x+w/2-.5),9*(.5-y-h/2),12*w,9*h]`。左框为 `[-2.598,-0.0495,5.772,5.985]`；plot_rect 是内缩绘图区，不自动画框；显式 panel 才是完整 frame。formula_rect 保留右列空间，steps 的各 panel 自行紧凑排布。页底线用极薄 panel 实现，避免把世界坐标的 line 当画布坐标。
- 章级 `presentation:"freeform"` + `proof_layout:"steps"` 关闭自动大标题、problem 与整张白卡；页眉/章节/标签/公式分别声明 text，图框与步骤分别声明 panel，并用已有 reveal/hide 安排显隐。只填 reference_yellow 或 steps 而继续 standard，不满足此基线。
- text.position 是文字中心，不是左上角；max_width 是最大宽度，不是左对齐开关。用现有文本生成逻辑量取实际宽度后设 `center_x=left_x+actual_width/2`；右上页眉按右边界设置 `center_x=right_x-actual_width/2`；换字、字体或 text_transform 后重新计算。模板文字已按现有渲染逻辑测宽；换成自己的文字不能原样沿用中心坐标。右卡内左边距示例0.18画面单位。
- 当前 geometry-1.9.6 无 font_weight/align/font_family/header/frame 等新字段。现有运行器对 paper 的 body 且 font_size=36 使用粗体；模板借 max_width 限制实际大小，得到小标识和下行粗章节。该兼容方法依赖实际文本宽高，不能对任意长标题保证同字号；须测宽高并核对参考。不得用重复叠字模拟粗体。math/serif 仍走现有字体规则。
- 面板 stroke_width=1，shadow:true + shadow_style:"outline"；具体偏移及安全边界见下文。主几何线宽依本题和参考另定，不能把全部线条一律加粗。模板不含数学题图，world_bounds 必须按真实对象及运动范围重新设定，不能从 panel 坐标推断数学坐标。

若实时 contract/运行器不足以表达已确认要求，记录最小能力缺口、期望行为与当前支持字段，按[维护与验收](maintenance-and-qa.md)及当前授权进行必要的最小扩展与验证；授权未覆盖扩展时，说明缺口并确认所需授权。明确仍未实现的差异，不把近似模板标为像素一致。仅更新 Skill 不授予修改旧项目的权限；已有项目修订须有覆盖该项目的明确授权。

#### 布局结构验收证据

“沿用”必须在项目验收记录保留参考与本期的同阶段截图（或参考旧分镜的已核对结构及本期截图），记录所取章节/时间、裁去播放器后的内容画布、归一化框位置与区域比例，以及 header、章节、图框四边、步骤顶对齐、字体/线宽/轻影的逐项对照。可用现有关键帧，不要求每次额外生图或重配音；只有旧分镜时明确缺少参考像素证据，不能声称像素复刻。基线坐标用于定位，不是忽略可读性或用户新要求的机械门槛；记录必要偏差及原因。仅改了色板、漏左框、回到居中大标题或大公式卡，应判为结构未通过并修正。

结构/schema/文字边界检查不等于视频视觉通过；真实帧仍需检查裁切、遮挡、手机可读性以及动画前中后。文档或模板维护可以不渲染媒体，将实际视频验收留给生产代理，并准确标明未验证部分。

### 独立片头引入（策划规则）

新纸面风格片头按讲解关系组织动态构图，不把固定左文右卡当强制模板。可采用“中心设问 → 已显示元素整组缩小并侧移，为新重点让位 → 倒推关系横跨画布 → 回到稳定题图”的路线；这是可选策划示例，不是每题必走的固定镜头表。短语按语义组进入，用“目标 → 缺什么 → 添一笔”的关系组织视线；横竖画幅分别适配，不能把横版布局机械挤进竖版。

片头最多安排1–2次主版式重排，不每句翻页、不让镜头乱飞；回到正式证明图后保持图形位置和比例稳定，以局部边、角、刻痕强调推进。重排时已显示的几何组、点名、标签、刻痕及对应说明作为一致的视觉组连续缩移，运动中和终点均检查标签跟随、相对位置及可读性，不能只移动线条而把标签留在原处，也不能靠隐藏后跳到另一处冒充连续运动。

待证目标与已知条件在文案和视觉分组上严格分开，明确标注“待证/目标”与“已知”；尚未证明的关系不得混入已知区、配成已成立的刻痕或提前显示为结论。新重点出现时仍保留必要的已知参照，不以版式重排替代数学依据。

约 0–12 秒只是参考片的观察区间，不是固定片头模板或时长要求。片头长度、短语及动作起止服从本期锁定稿与实际音频；没有独立引入口播时保留直接进入题图，不为套风格强加 12 秒、改口播、重配音或插入无依据停顿。不强塞参考片的收藏 CTA、品牌、水印，也不复刻其异常转场。参考正式题图中的已知卡曾整体显示，不能把本风格“条件逐项出现”的策划建议当成原片逐字进入的观察事实。

上述为策划意图，不新增 runtime 字段。可使用既有 `presentation:"freeform"` 为自行声明的图元留出画布，图形及文字的连续缩移须逐项映射实时 contract 支持的动作；“整组”是视觉一致性要求，不代表存在新的 group/scale/camera 动作。自动纸卡仍只有细边框，不默认带阴影；可自行声明 panel 并显式设置 shadow:true，默认 soft 轻影只露在框外；outline 是无填色的偏移细框，不给题图内部铺灰面。铅笔、橡皮、靶心等示意也须核对 contract 与现有资产，未实现时明确缺口，不能写未知字段或声称已支持。

已完成片头的具体画面与验收结论留在对应项目记录，不把单题对象或媒体写入通用 Skill。每次新题仍须查看本次输出重排前、运动中、终点及进入正文的真实帧；旧片通过或引擎能力测试不代表新动态片头已通过，也不自动证明连续缩放。“整组”仍是视觉一致性要求，不新增 group/scale 字段或动作。

本规则用于后续 paper_guided 策划或下一次已授权片头修订，不自动迁移已渲染视频。已直接进入题图的版本仍按其实际画面描述，不能因补充本规则就声称该片已含独立引入。

### 独立步骤框（geometry-1.9.6）

新纸面分镜采用紧凑、左对齐的独立推理框，按内容决定高度和留白，不机械堆叠三个等高大白卡。显式选章级 `proof_layout:"steps"` 关闭自动整张白卡；仅支持 paper_guided，classic+steps 明确拒绝。可与 `presentation:"freeform"` 组合，以 text 自行声明页眉与小阶段标题；standard 保留正式标题与 problem。两种组合均保留 plot_rect/formula_rect 与原动作时钟。省略新增字段仍保持旧图像、标题及转场，历史输出不自动迁移。

框用 `panel` 的画布坐标 `rect:[cx,cy,w,h]` 声明，标题、公式另用 text，继续使用 text_transform 与现有文本预算。panel 默认为细边、白底、无阴影、无底边强调。`shadow:true` 配省略/`shadow_style:"soft"` 保留原外露浅影条（偏移[0.06,-0.06]）；参考语法显式选 `shadow:true, shadow_style:"outline"`，得到固定偏移[0.0375,-0.0375]、#7C7965、stroke_width=1、无填色的空心细框，4:3画布宽960时相当于右下3像素。outline 没有 shadow:true 会拒绝，不额外占对象数。`accent:"#RRGGBB"` 只加当前步骤彩色底边。panel 位于几何和文字下方，shadow 在 panel 下方；透明题图框可用 fill_opacity:0，outline 仅有细线、不填灰面。框、选定阴影偏移和描边必须完整处于画布安全边界，几何仍守 plot_rect。自动纸卡不默认带阴影。

步骤边色、标题色与图中对应关系使用同一语义色；同一对比较对象保持淡红/淡绿等一致映射，区域使用已有 polygon/sector 的低透明填色（建议0.08–0.16），不得遮住边、角、标签。彩色底线只提示当前步骤，不代表命题已经证明；待证、已知与推导结论保持分开。点名与几何标签尽量外置，避开填色区域重叠内部；使用 label_offset 做局部避让，固定外置点名可显式 label_mask:false，不扩展全局 mask 逻辑。多个步骤框需留间距、控制短句，按手机宽度检查可读性，不能为塞框缩小到不可读。

panel 仅支持 reveal（默认或 style:"fade"）和 hide，不新增任意移动、缩放或文本动作；需要不同底线状态时显式声明替换框并安排显隐。steps 章最多144对象（较120增加20%），single 仍为120；freeform+steps 同样为144；其他动作、文本与时长预算不变。通用合成示例见 `examples/paper_steps.json`；每期项目仍需真实音频及当前画面验收。

### 参考纸面字体与标签（geometry-1.9.6）

新 paper_guided 分镜显式填写顶层 `paper_palette:"reference_yellow"`，统一所有章节（含片头）的底色 #FAF4D0；只允许该既定值，classic 使用会明确拒绝。它只改背景，不隐式改对象颜色、画幅或帧率。省略时保持旧纸面 #F4F1E7 / classic 黑底。建议深墨 #25251F、框边 #696957、面色 #FFFBE4，以及一对锁定的语义色（例如红 #975139 / 绿 #627A68）；配色由对象显式声明，不误称自动调色。

text 与 point 可选 `typography:"body"|"math"|"serif"`：body 默认沿用微软雅黑；数学正文用 math（Cambria italic，△∠≅≥≤∥等数学符号由 Cambria Math 正体绘制，中文和全角标点定向宋体正体）；中文数学注释可用 serif（SimSun/本机名称宋体）。所有实际字体、字形样式参与文本缓存键。不接受任意字体名，不新装 LaTeX 或字体；缺所需字体时明确报错。短公式用独立 text，既有 formula 动作字体不变；不要臆造 formula.typography。

固定且外置的 point 标签可显式 `label_mask:false` 去掉底色块，默认 true 不变；配合 label_offset 保持整段路径可读，不能以关遮罩代替避让。text_transform 继承原 typography，连续 text 复制要求源目标 typography 一致；点复制要求 typography 与 label_mask 一致。正式图稳定后再局部强调，不扩展全局 mask 逻辑。

通用短例 `examples/reference_paper.json` 演示黄底、细框偏移影、紧凑步骤框、数学/中文混排及 freeform 章节转场；它是静默能力样例，不证明任何项目实际音频、4K60全片或动态片头已通过。

### 片头大字粗体（typography:"heavy"，geometry-1.9.7）

仅 paper_guided 的 text 可选 `typography:"heavy"`：微软雅黑 BOLD，任意 font_size（最大 80），用于片头“两层大字”标题（上行小号深墨 + 下行大号红色关键词）。opt-in：省略或 body/math/serif 的字重规则完全不变（body 仍只在 36 号加粗）；classic_black 使用会被拒绝，point 标签不可用。不得用叠字模拟粗体。参考片头语法：左侧两层大字逐句替换、右侧横线纸卡以简单图元（同心圆靶心、箭头、问号、铅笔多边形）演示口播关系，卡片内容最后整组转入正式题图；各期按本期口播与音频编排，不照搬参考片文字或品牌。

### 视线与三层视觉关系

按 [geometry 导演提示词](../assets/engine/prompts/geometry_director.md#数学语义短句与视线引导)逐数学语义短句规划，先在图中看见依据，再在卡片读到推导。绘图区按数学角色组织三层：底图保留稳定的题设与空间参照；active 只突出当前指认或比较组；结论层保留已经讲明的关键关系及结果，不预示尚未推得的答案。这里的“层”是视觉职责，不是可任意写入 JSON 的字段。主要使用对象类型已有的 color/stroke_width/fill_opacity、语义配色和有序 reveal/hide 实现；并非所有对象都支持这些字段，须逐类型检查 contract。geometry-1.9.2 不新增自动 dim、z-index 调整或卡片阴影能力。

底图须仍可辨认；辅助线在视觉上从属于主几何，以既有虚线/较轻描边和有序呈现区分，不能宣称自动置底或写入 z_index。active 可以包括成组比较的边或角，一次只表达一个主要关系；角填使用半透明，不能遮住射线及邻近点名。点名、角标、刻度标签及必要遮罩优先可读，复用既有渲染层位并以实际位置避让；新强调动作不改变层位，不能保证所有标签自动顶层或无碰撞。默认自动白卡只有细边框；显式 panel 可使用 shadow:true，只有 panel 接受该字段，不可给其他对象填写 shadow，也不提供用户可写的 z_index。

临时强调在语义结束/下一焦点接手时恢复；已经证明且后续仍需使用的刻痕、角标等结构性标记可保留。恢复回到强调前的可见性及基础样式，不能把隐藏辅助对象亮出，也不能抹掉仍在使用的数学依据。延续相同数学关系时保持同组的结构标记和语义对应，避免每个字闪烁；highlight(style:"emphasis") 是脉冲且自动回落，不是持续高亮开关。三层设计不授权重排原稿、重配音、移动正式证明主图或改变旧 classic_black 风格；片头构图按上节及当前任务授权单独规划。

### 讲解与动作规划
先通读完整稿并核对数学，按用户改稿授权决定原稿保留、纠错轻改或原创重构；风格选择本身不授权重写锁定稿或重新配音。发现数学问题先核实，按现有改稿与音频版本规则处理；不复制参考视频原稿或机械套用参考单题。按本题需要组织：痛点/目标钩子 → 改写目标 → 指出还缺的关系 → 已有条件怎样凑 → 逐条构造辅助线 → 展示对应关系 → 阶段小结“这一步给了什么” → 回扣原目标，末尾一句迁移性提问。每步保留“缺口 → 依据 → 结论”，不得凭主题补造数学条件。

- 探路阶段可虚线生长，确定后实线；每条新线明确起点、终点、方向及有依据的相等约束。已有 reveal(style:"draw") 可逐笔创建线；虚实切换使用独立声明的重合线和 hide/reveal，不宣称引擎有未实现的单对象虚实变形。延长线按实际端点定义连续的新增线段；不要用整线淡入冒充定向生长。
- 三角形保持原位，使用该项目锁定的一对语义色（例如红/绿；已锁定红/蓝项目沿用），对应边、角、淡填色保持一致；全等证据重点落在边、刻痕、角弧的对应；不能把主图漂移搬走代替证据链。物体复制/叠合仅在旁白明确需要时使用。
- 右卡条件逐项出现：可用已有 text + reveal/fade（每条独立对象，画面坐标在卡内），或 formula 的累计短行。条件齐备后才让结论淡入；formula 替换会替换整组，不能声称自带逐条追加。每组同时出现的文字遵循现有 text budget；阶段结束及时 hide。
- 参考经局部取证支持虚线探路延伸、实线构造、先边后夹角再结论，不支持推断原片搬动叠合、精确缓动或精确字体。常规动画0.3–0.6秒仅为建议，实际起止服从音频锚点和可读性。
- 无底部逐句字幕；保留必要条件、数学式和阶段短结论。不要复制品牌水印、平台尾页、收藏关注喊话、来源视频作者的姓名或身份自称（本账号讲题人自己的口吻不受此限）。音色与语速独立选择，风格切换不授权重配音。

## 验收边界
主题选择不能放宽数学、连续运动、音频和真实画面验收。首次主题 smoke 使用非私人两三角形、逐笔辅助线、红蓝对应、条件→结论卡及 synthetic_fixture 音轨；只证明已检查的主题/动作和媒体流，不证明 ASR、原片复刻或正式成片通过。旧默认及显式 classic_black 要保持相同画面。媒体、原始参考、运行日志与临时测试产物均留在 Skill 外。

封面独立遵循现行双封面规则；用户本次明确指定封面风格时覆盖。视频选择 paper_guided 不自动把黑板风封面变成纸面风格。

style 不隐式修改 canvas、输出分辨率、帧率、音色或语速；保留项目与用户设置。低清 smoke 的尺寸仅属于测试命令，不改项目最终 canvas。
